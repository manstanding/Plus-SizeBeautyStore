2. Open the extracted Plus-Size-Beauty-Store folder.
3. Select ALL files INSIDE that folder. Do not drag the outer folder itself and do not upload the ZIP.
4. Drag the selected files into GitHub's "Drag files here" area.
5. Wait until every filename appears in GitHub.
6. Scroll to the bottom.
7. In the commit message, use: Initial PLUS SIZE BEAUTY website

PART F — CUSTOM DOMAIN (DO THIS AFTER THE GITHUB PAGES ADDRESS WORKS)
You need your exact GoDaddy domain name for these steps.
1. GitHub repository > Settings > Pages.
2. Under Custom domain, enter your exact domain and click Save.
3. THEN open GoDaddy > your domain > DNS / Manage DNS.
4. For the root/apex domain, use these GitHub Pages A records:
   @  A  185.199.108.153
   @  A  185.199.109.153
   @  A  185.199.110.153
   @  A  185.199.111.153
5. For www, create/use:
   www  CNAME  manstanding.github.io
   Do NOT include /Plus-Size-Beauty-Store in the CNAME target.
6. Do not use wildcard DNS for this setup.
7. Extra conflicting @ A/AAAA/ALIAS/ANAME records or conflicting www CNAME records can prevent correct HTTPS provisioning. Do not delete unrelated DNS records blindly; compare them first.
8. DNS can take up to 24 hours to propagate.
PASS RESULT: GitHub Pages accepts the custom domain and the domain opens the PLUS SIZE BEAUTY site.
